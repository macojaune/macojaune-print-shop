# 13 — Memebank : la diversion

Prototype local, 1er octobre 2026. Pas de déploiement ni de données réelles.

- Trois étapes numérotées : courrier, dossiers, coffre VHS.
- Les mêmes panneaux, jauges, scénarios et commandes que le hangar.
- Banque élargie, deux employés occupés, jusqu’à huit clients.
- Les compteurs et les piles continuent après les quotas de démonstration.
- Zoom/pan et cadrage de chaque poste ; sur mobile, les actions ne masquent plus les piles.
- Coffre exclusivement VHS, avec une cassette dégagée sur le tapis.
