# Terraink — piste cartographique

Proposé par Marvin pendant l'exploration de Maco’misyon : https://github.com/yousifamanuel/terraink

Documentation consultée le 11 septembre 2026 : création de posters à partir d'OpenStreetMap ; recherche de lieux ou coordonnées ; couleurs par couches (routes, eau, parcs, bâtiments) ; export PNG, PDF et SVG par calques ; MapLibre, OpenFreeMap et Nominatim. Le README indique AGPL-3.0 pour les changements depuis le 3 avril 2026, et MIT pour le code antérieur. Ne pas supposer que l'intégralité de la version actuelle est MIT à partir de l'étiquette GitHub.

Usages proposés : affiches de missions, cartes d'indices, visuels de spots Shootareas, fonds de cartes animés issus du SVG. Pour un géocaching, Terraink peut aider à produire le support ; les points de passage, indices, validation, états de progression et éventuels services de géolocalisation restent une couche à concevoir. Ces propositions ne sont pas des fonctionnalités vérifiées dans Terraink.

Inspection documentaire seulement. Aucune installation, aucun fork ni intégration de Terraink réalisés. Le petit prototype interactif de plateau utilise sa propre géométrie Three.js et des données fictives.
