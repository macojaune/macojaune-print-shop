# Vérification de la galerie

11 septembre 2026, galerie de consultation locale seulement.

- Captures de la galerie en 1440, 539 et 390 pixels de large, inspectées visuellement.
- Aucun dépassement horizontal aux trois tailles.
- Les trois choix de direction changent l’image, la description et les spécimens ; les images se chargent.
- Les fichiers de police locaux se chargent, Tanker est disponible dans le navigateur.
- Les trois animations se terminent et le bouton est réactivé.
- Avec réduction des mouvements, aucun objet animé actif après déclenchement.
- Aucune erreur JavaScript observée pendant ces parcours.

Le détecteur Impeccable a fonctionné en mode regex dégradé, ses dépendances de parsing n’étant pas présentes. Il ne constitue pas une validation de contraste calculé. Les avertissements concernent Space Grotesk, volontairement conservée comme police existante Macojaune, et les deux bords du petit repère animé, qui dessinent le repère lui-même.

Les planches ont reçu une relecture visuelle indépendante sans défaut matériel bloquant à leur présentation. Les dessins typographiques générés ne constituent pas une fonte finale. Les données sont illustratives. Aucun parcours sur les projets ni aucune publication n’est déclenché par la démonstration.
