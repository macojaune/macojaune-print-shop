# Planches Maco’misyon

Ouvrir `index.html` pour consulter la nouvelle synthèse Signal × Pocket, les trois pistes initiales, leurs spécimens typographiques et l’essai d’alerte. Le dossier fonctionne en local et ne déclenche aucune publication. Garder les fichiers de la galerie, les images et `assets` ensemble.

Serveur de consultation lancé pour cette session : http://127.0.0.1:58011/.

Pour le relancer depuis ce dossier :

```sh
python3 -m http.server 58011 --bind 127.0.0.1
```

## Livrables

- `01-signal-jaune.png`
- `02-club-komisyon.png`
- `03-maco-pocket.png`
- `04-signal-pocket.png` : synthèse après le choix de Marvin, affichée en premier.
- `lecture-des-planches.md` : lecture comparative et recommandation.
- Les fichiers `prompt.md` / `prompt` associés : instructions exactes du générateur intégré et corrections.

Les images finales font 1536 × 1024 pixels. Les fichiers suffixés `v1` conservent des versions intermédiaires ; ils ne sont pas présentés dans la galerie. Les images dans `references` sont des captures des sites consultés, conservées seulement comme références locales. Certains sites sont protégés par authentification ; la galerie ne publie pas ces captures.

Les planches sont des propositions générées. Les textes, pictogrammes et objets dessinés restent à finaliser après choix. Les compteurs sont fictifs. Aucun code produit, site déployé ou automatisme n’a été modifié.
